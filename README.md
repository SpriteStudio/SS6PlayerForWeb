### SpriteStudio 6 Player for Web

> [!IMPORTANT]
> 後継の **SpriteStudio Player for Web** へ移行してください。
>
> <https://github.com/cri-middleware/SSPlayerForWeb>
>
> 移行先のパッケージは次のとおりです。
>
> - `ss6player-pixi` → [`@spritestudio/ssplayer-pixi`](https://www.npmjs.com/package/@spritestudio/ssplayer-pixi)
> - `ss6player-lib` → [`@spritestudio/ssplayer-core`](https://www.npmjs.com/package/@spritestudio/ssplayer-core)
> - `ss6player-rpgmakermz` → `ssplayer-rmmz`（[RPG ツクール MZ で使う](https://cri-middleware.github.io/SSPlayerForWeb/ja/usage/rmmz)）
>
> 移行の手順は [SS6Player からの移行](https://cri-middleware.github.io/SSPlayerForWeb/ja/migration_from_ss6) を参照してください。

ドキュメントはこちらです。

https://github.com/SpriteStudio/SS6PlayerForWeb/wiki
